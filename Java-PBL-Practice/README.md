# Java PBL Practice Questions

## 📚 Project Description
This repository contains complete solutions to 20 Java programming questions provided for PBL (Project-Based Learning) examination practice for SY-A, Odd Semester 2026-27. All solutions are written in simple Core Java, designed to be beginner-friendly and easy to understand during practical examinations.

## 📊 Total Questions: 20

## 📝 Question List

1. **Perfect Number Checker** - Check if a number is a perfect number
2. **Pattern Printing** - Print three different patterns (stars, numbers, symbols)
3. **Letter and Special Character Counter** - Count letters and special characters in a string
4. **Library Book Manager** - Sort books and authors alphabetically
5. **Fibonacci Series** - Print Fibonacci numbers from 1 to 200
6. **Reverse Digits in Array** - Reverse digits of each number in an array
7. **Multiplication Table** - Print multiplication table of a given number
8. **Largest and Smallest in Array** - Find largest and smallest elements
9. **Word Counter** - Count words in a sentence without StringTokenizer
10. **Character Frequency** - Count frequency of a character in a sentence
11. **Prime Numbers in Array** - Count and print prime numbers from array
12. **Vowel Counter** - Count vowels in a sentence
13. **Vowel to Consonant Converter** - Change vowels to previous consonants
14. **Odd Index Elements** - Display elements at odd indices and calculate sum/average
15. **Sum of Digits** - Print sum of digits for each number in array
16. **Armstrong Numbers in Range** - Print Armstrong numbers within a range
17. **Palindrome Words** - Find and print palindrome words in a string
18. **Capitalize First Letter** - Make first letter of each word capital
19. **Factorial Calculator** - Calculate factorial of a number
20. **Array Statistics** - Find smallest, largest, and sum of remaining elements

## ⚙️ Requirements

- **Java Development Kit (JDK)**: Version 8 or higher
- **Operating System**: Windows, Linux, or macOS
- **Text Editor/IDE**: Any Java IDE (Eclipse, IntelliJ IDEA, VS Code) or simple text editor

## 🚀 How to Compile and Run

### Method 1: Using Command Line

1. **Navigate to the question folder:**
   ```bash
   cd Java-PBL-Practice/Question01
   ```

2. **Compile the Java file:**
   ```bash
   javac Q1.java
   ```

3. **Run the compiled program:**
   ```bash
   java Q1
   ```

### Method 2: Using IDE

1. Open your Java IDE (Eclipse, IntelliJ IDEA, VS Code, etc.)
2. Import or open the `Java-PBL-Practice` folder
3. Navigate to any question folder
4. Right-click on the Java file and select "Run"
